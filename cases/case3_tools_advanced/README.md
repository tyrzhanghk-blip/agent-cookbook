# 案例3：工具（进阶）

## 学什么
- 一个 Agent 可以挂多个工具，模型自己决定调用顺序（这里是先查天气、再要穿衣建议）。
- `output_type=SomePydanticModel`：让 Agent 的最终输出严格符合这个 schema，`result.final_output` 直接是该模型的实例。
- **一个常见的工程坑**：让同一个 Agent 在一轮里"既调用多个工具、又产出严格结构化输出"，对模型能力要求很高，
  能力不够强的模型容易跳过真正的工具调用，直接按字段名编答案。
  **更稳妥的做法是拆成两步**：一个 Agent 只管调工具产出文本，另一个 Agent 只管把文本整理成结构化数据。
  各自的任务更简单，模型完成得也更可靠。

## 怎么运行
```bash
uv run python cases/case3_tools_advanced/main.py
```

## 预期输出
先打印调研阶段的工具调用结果（文本），再打印格式化后的 `TravelPlan` 各字段。
