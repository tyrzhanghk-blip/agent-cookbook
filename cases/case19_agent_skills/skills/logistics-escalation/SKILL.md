# 物流异常升级指南（内部 SOP）

## 判级标准
- P1：丢件/签收未收到/商品破损 → 立即升级，优先赔付
- P2：物流超 72 小时未更新 → 联系承运商核查
- P3：配送延迟但仍在承诺期内 → 安抚 + 告知预计时间

## 升级路径
- P1 直接创建工单流转至物流专项组（虚拟组号 LOG-EXPERT）
- P2/P3 由一线先处理，24 小时未解决再升级

## 话术要点
- 不承诺具体到某天必达，用"预计"+ 缓冲时间
- P1 场景必须先致歉再给方案
