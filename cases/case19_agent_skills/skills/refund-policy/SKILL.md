# 退款政策处理指南（内部 SOP）

## 受理条件
- 下单 7 天内且商品未使用（吊牌完整）
- 质量问题不受 7 天限制，需用户提供照片凭证

## 政策边界（必须遵守）
- 单笔超过 5000 元的退款：不能直接承诺，回复"已为您升级至专属通道，24小时内会有专员联系"
- 生鲜/定制类商品：不支持无理由退货，质量问题除外
- 严禁承诺"秒退"，标准口径是 1-3 个工作日到账

## 处理流程
1. 确认订单号与购买时间
2. 判断属于哪种受理条件，明确告知用户结果
3. 符合条件的：说明退款金额、到账时间
4. 不符合条件的：说明原因 + 提供替代方案（换货/优惠券补偿）
